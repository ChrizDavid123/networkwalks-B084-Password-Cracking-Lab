# networkwalks-B084-Password-Cracking-Lab
I am happy to share my success in completing my week 3 task as an intern on NetworkWalks Batch BO84!

In this week's lab, I used different password-cracking tools, specifically brute-force attacks, to open 3 different PDF files encrypted with a password using tools such as the hash calculator and password cracker from NetworkWalks, John the Ripper, and PDF hash extractor. 

The following are the tasks completed in this week's activity:
- Downloaded John the Ripper and activated it on the Johnny GUI application
- Prepared tools from NetworkWalks and PDF hash extractor on my browser
- Gathered PDF hash values using the hash calculator and extractor
- Collected passwords using password cracker and John the Ripper
- Opened up encrypted PDF files

This activity taught me the importance of using strong passwords and how weak passwords allow attackers to successfully exploit them. Overall, I enjoyed this fun penetration testing activity, finding new ways to test the security strength of a user, helping me gain practical skills and confidence in this field.
